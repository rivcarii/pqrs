# Seguridad

Sistema de PQRS del SIAU · MiRed Barranquilla IPS S.A.S. La política completa está en [`docs/SEGURIDAD.md`](docs/SEGURIDAD.md).

## Cómo reportar una vulnerabilidad
No abras un *issue* público. Usa **Security ▸ Report a vulnerability** de este repositorio (reporte privado) o escribe al líder de Gestión de la Calidad. Indica qué viste, cómo reproducirlo y qué datos podrían quedar expuestos. **No incluyas datos reales de usuarios.**

## Qué no debe estar nunca en este repositorio
Datos de pacientes o usuarios, el consolidado real (`*.xlsx`), contraseñas, tokens, llaves, el tema del push (ntfy) ni credenciales de `clasp`. El repositorio es público: solo contiene código y datos ficticios.
